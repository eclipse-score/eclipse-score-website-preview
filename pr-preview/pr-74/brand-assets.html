VISUAL DIRECTION

Design principles

These principles guide how S-CORE presents itself across project materials.

Clear

Make information easy to find, read and understand.

Consistent

Use shared visual elements to connect project materials.

Accessible

Support readable contrast, responsive layouts and inclusive access.
